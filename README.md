# Landing page - O Senhor dos Anéis

Projeto de estudo em HTML, CSS e JavaScript puros (sem build).

- Cabeçalho responsivo com menu mobile
- Seção de abas (povos da Terra-média)
- Planos (jornadas), seções imagem + texto e imagem + lista
- FAQ com transição
- Rodapé e variáveis CSS

Para ver localmente, abra o `index.html` no navegador.
